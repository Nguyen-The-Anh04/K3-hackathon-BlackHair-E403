# VLearn Ôn tập nhanh — CP2 prototype

Prototype CP2 cho flow: đoạn tài liệu → cấu hình → làm 3 câu trắc nghiệm → xem đáp án/giải thích/citation → tổng kết → làm lại.

## Chạy thử

Mở trực tiếp `index.html` bằng trình duyệt. Prototype không cần cài dependency hoặc API key.

## Phạm vi CP2

- Có thể bấm xuyên suốt flow chính từ đầu đến cuối.
- Câu hỏi, đáp án, điểm và citation đang dùng dữ liệu giả được khai báo trong `app.js`.
- Chưa tích hợp AI thật; phần này dành cho CP3.
